Приклад 7: Конфлікт стилів №1

Якого кольору має бути цей текст? Синього чи червоного?

Результат: Текст став синім.

Пояснення: Спрацював селектор класу .text-blue. Кортеж специфічності для класу — (0, 1, 0), а для селектора тега p — (0, 0, 1). Оскільки (0, 1, 0) > (0, 0, 1), клас перемагає тег.

Приклад 8: Конфлікт стилів №2

Елемент із комбінованими правилами та ідентифікатором.

Результат: Елемент має золотий фон.

Пояснення: Конкурували селектори #unique-box та main p.box-style. Кортеж ідентифікатора — (1, 0, 0). Кортеж комбінованого селектора (1 клас + 2 теги) — (0, 1, 2). Оскільки (1, 0, 0) > (0, 1, 2), ID беззаперечно перемагає, попри довжину іншого селектора.
