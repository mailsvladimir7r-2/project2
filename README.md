# Демонстрація CSS-селекторів та специфічності

## Мета проєкту
Навчальна вебсторінка створена для наочної демонстрації роботи різних типів CSS-селекторів, псевдокласів, станів фокусу та правил вирішення конфліктів специфічності.

## Використані технології
* HTML5
* CSS3

## Перевірка результату
Для перевірки достатньо відкрити файл `index.html` у браузері або перейти за посиланням опублікованого сайту. Усі блоки відображають коректні стилі згідно з кортежами специфічності, а кнопка реагує на наведення та фокус.
